Three instruments for design systems.

A design decision should mean the same thing in Figma, in the token file, and on screen. These check that it does — and tell you where it stopped being true.

Contrast Matrix

Paste a palette, get every pair. Contrast is computed with the WCAG 2.1 relative-luminance formula and judged on the unrounded ratio, against both AA and AAA thresholds.

Token Foundry

Build a design token set with the contrast check built into the editor, then export the JSON. Colour pairings get checked against WCAG 2.1 AA as you make them, not in review — contrast only; the rest of conformance is still yours.
