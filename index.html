Contrast Matrix

Contrast is computed with the WCAG 2.1 relative-luminance formula and judged on the unrounded ratio, against both AA and AAA thresholds.

Token Foundry

Build a design token set with the contrast check built into the editor, then export the JSON. Ensure the values you are adding are correct and align with WCAG 2.1 AA standards before creating an export file.
